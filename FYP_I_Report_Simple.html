ABSTRACT

The AI-Powered Recruitment Platform is a comprehensive web-based application designed to revolutionize the recruitment process by integrating artificial intelligence technologies. The platform addresses traditional recruitment limitations by automating CV analysis, providing intelligent job matching, and offering real-time communication features.

The system serves two main user roles: Candidates and Recruiters/Admins. Candidates can upload CVs, browse jobs, apply for positions, and receive AI-powered career guidance. Recruiters can post jobs, review applications, access AI-analyzed candidate profiles, and manage platform analytics.

Technology Stack: React, Node.js, MySQL, Google Gemini API

1. INTRODUCTION

1.1 Project Overview

The AI-Powered Recruitment Platform is a modern web-based solution that leverages artificial intelligence to streamline recruitment processes. The platform serves as a bridge between job seekers and employers, providing intelligent tools for both parties.

1.2 Problem Statement

Traditional recruitment processes are time-consuming, biased, and inefficient. Manual CV screening, lack of intelligent matching algorithms, and limited scalability are major challenges in current recruitment systems.

1.3 Objectives

Main Objectives:

  1. Develop a comprehensive recruitment platform with AI capabilities
  2. Implement secure user authentication and role-based access control
  3. Create an intuitive and responsive user interface
  4. Integrate AI for automated CV analysis and job matching
  5. Provide real-time notifications and communication features

1.4 Scope and Limitations

Scope: Web-based platform with CV analysis, job matching, and user management.

Limitations: Currently supports text-based CV analysis only, requires internet connectivity.

2. LITERATURE REVIEW

2.1 Existing Systems

Traditional ATS systems like LinkedIn and Naukri.com focus on job posting but lack advanced AI capabilities. Modern platforms like HireVue and Eightfold AI offer AI-powered features but are expensive and complex.

2.2 AI in Recruitment

AI applications include NLP for CV analysis, predictive analytics for candidate success prediction, and automated candidate ranking. Benefits include reduced bias, faster screening, and improved hiring decisions.

2.3 Technology Analysis

The project uses React for frontend, Node.js for backend, MySQL for database, and Google Gemini API for AI integration. These technologies provide scalability, performance, and modern development practices.

3. SYSTEM ANALYSIS AND DESIGN

3.1 Requirements Analysis

Stakeholder analysis identified three main user groups: candidates, recruiters, and administrators. User stories were developed to understand system requirements and user expectations.

3.2 Functional Requirements

The system includes user authentication, CV upload and analysis, job management, application processing, AI-powered matching, and notification systems.

3.3 Non-Functional Requirements

Requirements include performance (response time <500ms), security (JWT authentication), usability (responsive design), and reliability (99.9% uptime).

3.4 System Architecture

The system follows MVC architecture with RESTful API design. It includes frontend (React), backend (Node.js), database (MySQL), and AI services (Google Gemini).

3.5 Database Design

The database includes tables for users, jobs, applications, and notifications. Entity-relationship diagrams were created to ensure proper data relationships and normalization.

3.6 UI/UX Design

The interface follows clean, modern design principles with intuitive navigation. Wireframes were created for all major pages including landing page, dashboard, and job management interfaces.

4. IMPLEMENTATION

4.1 Development Environment

The project was developed using Visual Studio Code, Git for version control, npm for package management, and MySQL Workbench for database design.

4.2 Frontend Implementation

Frontend was built using React 18.2 with modern hooks, Tailwind CSS for styling, and Axios for API communication. Key components include authentication forms, dashboards, and job management interfaces.

4.3 Backend Implementation

Backend uses Node.js with Express.js framework, MySQL database with Sequelize ORM, and JWT for authentication. RESTful APIs were implemented for all major functionalities.

4.4 AI Integration

Google Gemini API was integrated for CV analysis and skill extraction. The system provides compatibility scoring (0-100) for job-candidate matching and includes a career guidance chatbot.

4.5 Testing and Quality Assurance

Comprehensive testing included unit testing, integration testing, and end-to-end testing. The system achieved 95%+ code coverage with automated test suites.

5. RESULTS AND DISCUSSION
